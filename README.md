# INFERNO: A Discord Bot for Simplified Learning

INFERNO is a Discord bot designed to simplify complex questions and provide clear, concise answers. It leverages the power of Discord's API to create an interactive learning environment where users can ask questions and receive simplified explanations. INFERNO is perfect for educational communities, study groups, and anyone looking to learn new concepts in a straightforward manner.

## Install

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/inferno.git
   cd inferno
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file in the root directory and add your Discord bot token:
   ```env
   DISCORD_TOKEN=your_discord_token_here
   ```

## Use

1. Run the bot:
   ```bash
   python bot.py
   ```

2. Invite the bot to your Discord server using the OAuth2 URL generated by the Discord Developer Portal.

3. Use the `!simplify` command followed by your question to get a simplified answer:
   ```plaintext
   !simplify What is the theory of relativity?
   ```
